For Windows and Linux

Explore your storage.

See the breakdown

Expand the folder tree or switch to a treemap. Pie and bar charts show how folders compare, while the largest-files list puts the biggest items within reach.

Narrow your search

Filter by file type, size, age, name, or path. Use regular expressions for precise matches, and adjust scan priority and throttling while you work.

Manage files in place

Inspect an item, then move, rename, duplicate, or delete it from the explorer. Create folders to put things in order without leaving the app.

Rename a whole batch.

Turn a list of files and folders into a consistent set of names. Preview every result before applying your changes.

  • Combine replacements, prefixes, suffixes, numbering, case, and extension rules.
  • Include or exclude names with text or regular expressions.
  • Save rule and filter templates for the next batch.

Export your scan.

Export a scan for a storage review, a cleanup plan, or your own records. Choose a report to share or a spreadsheet to work with.

Your disk.
Your terminal.

Explore folders with the standalone CLI on Windows and Linux, including servers over SSH. Navigate by keyboard, sort by size, and filter names as the scan runs.

Build and use the CLI ↗
dragabyte-cli

Explore the current folder

$ dragabyte-cli .

Write a JSON report

$ dragabyte-cli scan /data --json > usage.json

Use scans in your scripts

Export text or JSON with file sizes, folder totals, and completion status. Use the results in your own tools and workflows.

Explore a remote machine

Run the CLI’s management server and connect from the desktop Remote Dashboard to browse folders and scan storage. Use an SSH tunnel for encrypted access.
